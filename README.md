My personal portfolio and venture-studio site, built with a restrained bento-grid system and interactive TikTok and Eldorado analytics.

Live at https://Tobralla.github.io/goblin.industries/

- **DonutCoinShop** — B2B marketplace vendor account with $920.74 in sales across 284 orders and 290+ reviews (Dec 2025 — Apr 2026).
